# Java Fundamentals Learning Repository

## Description

This repository is a comprehensive collection of Java programs designed to teach and demonstrate fundamental concepts in Java programming. Organized by lecture topics, it covers everything from basic syntax to advanced algorithms, making it an excellent resource for beginners and a reference for experienced developers. This project showcases a structured approach to learning Java, with hands-on examples that build progressively in complexity.

## Features

- **Structured Learning Path**: Programs are meticulously organized into lectures, progressing from introductory concepts to complex topics like sorting algorithms.
- **Hands-on Examples**: Each topic includes practical code examples, complete with compiled .class files for immediate execution and testing.
- **Diverse Topics Covered**: Encompasses essential areas including data types, control structures, loops, pattern printing, functions, arrays, strings, string manipulation, bitwise operations, and sorting algorithms.
- **Educational and Professional Value**: Ideal for self-study, classroom instruction, or as a portfolio piece demonstrating Java proficiency and attention to detail.
- **Ready-to-Run Code**: All programs are self-contained, with clear comments and outputs, ensuring ease of understanding and modification.

## Project Structure

The repository is divided into lecture-based folders, each focusing on a specific topic:

- `lec1_intro/`: Introduction to Java programming basics.
- `lec2_dataType/`: Data types, variables, input/output operations, and pattern printing.
- `lec3_conditional/`: Conditional statements (if-else), comparisons, and switch cases.
- `lec4_loop/`: Loop constructs including for, while, and do-while loops, with practical problem-solving examples.
- `lec5_pattern/`: Programs for printing various patterns using loops.
- `lec6_fun_and_method/`: Functions and methods, including recursion and modular programming.
- `lec7Array/`: Arrays (1D and 2D), array operations, and search algorithms.
- `lec8String/`: String handling, input methods, and string functions.
- `lec9Stringbuilder/`: Efficient string manipulation using StringBuilder.
- `lec10operatorandBinaryNo/`: Operators, bitwise operations, and binary number manipulation.
- `lec11_sorting/`: Implementation of sorting algorithms such as bubble, selection, and insertion sort.

## Prerequisites

- Java Development Kit (JDK) installed (version 8 or higher recommended for compatibility).
- A Java-compatible IDE or text editor (e.g., Visual Studio Code, Eclipse, or IntelliJ IDEA) for editing and running code.

## How to Run

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   cd Java
   ```

2. **Compile a Java File** (if needed; .class files are pre-compiled):
   ```
   javac lec1_intro/First_class.java
   ```

3. **Run the Program**:
   ```
   java lec1_intro.First_class
   ```

   Replace `lec1_intro/First_class` with the desired lecture and class name. The output will display in the terminal, demonstrating the program's functionality.
